## Level 4: versions and trash

Users want to undo: overwriting a file keeps its old versions, and deleting a file moves it to a trash it can come back from. Add:

| Method | Behaviour |
|---|---|
| `{{overwrite_file}}(path, size) → int` | Uploads new contents of `size` bytes to the file at `path`, keeping the old ones. Returns the new version's number: a file starts at version 1, and each overwrite adds the next number. Returns `-1`, changing nothing, if there is no file at `path`, `size < 0`, or the new version doesn't fit the owner's quota. |
| `{{restore_version}}(path, version) → int` | Rolls the file back to `version`: every later version is discarded. Returns the file's size after the rollback (restoring the current version changes nothing). `-1` if there is no file at `path` or the file has no such version. |
| `{{restore_file}}(path) → bool` | Brings back the file most recently deleted from `path`, with all its versions and its owner. Returns `false`, changing nothing, if a file exists at `path`, nothing deleted from `path` is in the trash, or the restored file doesn't fit its owner's quota (all its versions count). |
| `{{empty_trash}}() → int` | Permanently removes everything in the trash and returns how many files that was. |

**Versions and quota.** Every version a file keeps counts against its owner's quota, so `{{overwrite_file}}` needs room for the whole new version and `{{restore_version}}` gives back the bytes of the versions it discards. A file's size is its current (latest) version's size: that's what `{{get_file_size}}`, `{{largest_files}}`, `{{folder_size}}` and `{{delete_file}}` report, and what a copy gets. A copy starts at version 1.

**Trash.** `{{delete_file}}` now moves the file to the trash. A trashed file doesn't count against any quota (all its versions' bytes go back to the owner) and isn't listed anywhere, and its path is free for a new file. The trash can hold several files deleted from the same path.

### Example

```
{{add_user}}("ana", 1000)                       → true
{{add_file_by}}("ana", "/ana/draft.doc", 300)     → 700
{{overwrite_file}}("/ana/draft.doc", 400)        → 2
{{get_file_size}}("/ana/draft.doc")              → 400
{{remaining}}("ana")                            → 300   (both versions kept)
{{restore_version}}("/ana/draft.doc", 1)         → 300
{{remaining}}("ana")                            → 700
{{delete_file}}("/ana/draft.doc")                → 300
{{remaining}}("ana")                            → 1000
{{restore_file}}("/ana/draft.doc")               → true
{{remaining}}("ana")                            → 700
{{empty_trash}}()                               → 0
```
