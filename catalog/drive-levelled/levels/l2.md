## Level 2: folders

The app's sidebar shows what takes up space in a folder. Add:

| Method | Behaviour |
|---|---|
| `{{largest_files}}(prefix, n) → list of strings` | Up to `n` files whose path starts with `prefix`, as `"path(size)"`: largest first, ties by path ascending (plain string order). An empty list if none match or `n` is 0. |
| `{{folder_size}}(prefix) → int` | The total size of the files whose path starts with `prefix`. `0` if none match. |

`prefix` is matched as plain text from the start of the path: `"/docs"` matches `"/docs/a.txt"` and `"/docs2/b.txt"`, `"/docs/"` matches only the first, and neither matches `"/archive/docs/c.txt"`. The empty prefix `""` matches every file.

### Example

```
{{add_file}}("/docs/a.txt", 200); {{add_file}}("/docs/b.txt", 500)
{{add_file}}("/docs/c.txt", 200); {{add_file}}("/music/song.mp3", 900)
{{largest_files}}("/docs/", 2)    → ["/docs/b.txt(500)", "/docs/a.txt(200)"]
{{largest_files}}("", 10)         → ["/music/song.mp3(900)", "/docs/b.txt(500)", "/docs/a.txt(200)", "/docs/c.txt(200)"]
{{folder_size}}("/docs/")         → 900
```
