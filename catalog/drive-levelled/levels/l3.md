## Level 3: users and quotas

The drive now has users, and each user has a storage quota. Add:

| Method | Behaviour |
|---|---|
| `{{add_user}}({{user_id}}, capacity) → bool` | Adds a user who can store up to `capacity` bytes. Returns `false` if the user already exists or `capacity <= 0`. |
| `{{add_file_by}}({{user_id}}, path, size) → int` | Like `{{add_file}}`, but the file is owned by the user and counts against their quota. Returns the user's remaining capacity after the upload, or `-1`, changing nothing, if the user doesn't exist, `{{add_file}}` would refuse it, or it doesn't fit. |
| `{{copy_file_by}}({{user_id}}, source, dest) → int` | Like `{{copy_file}}`, but the copy is owned by the user who copies it and counts against their quota, whoever owns `source`. Returns the user's remaining capacity, or `-1`, changing nothing, if the user doesn't exist, `{{copy_file}}` would refuse it, or it doesn't fit. |
| `{{remaining}}({{user_id}}) → int` | The user's capacity minus the bytes their files use. `-1` if the user doesn't exist. |

**Fitting.** A file fits when the user's used bytes plus its size are at most their capacity: filling a quota exactly is allowed.

New rules for what you already have:

- `{{add_file}}` still adds a file nobody owns. It counts against no quota, and neither do its copies made with `{{copy_file}}`.
- `{{copy_file}}` of an owned file makes a copy owned by the **same** user, counting against their quota. It returns `false`, changing nothing, if the copy doesn't fit.
- `{{delete_file}}` of an owned file gives its bytes back to the owner.
- `{{largest_files}}` and `{{folder_size}}` list every file, whoever owns it.

### Example

```
{{add_user}}("ana", 1000)                                → true
{{add_file_by}}("ana", "/ana/photo.jpg", 600)             → 400
{{add_file_by}}("ana", "/ana/video.mp4", 500)             → -1    (doesn't fit)
{{add_file_by}}("ana", "/ana/notes.txt", 400)             → 0     (exactly full)
{{add_user}}("ben", 800)                                 → true
{{copy_file_by}}("ben", "/ana/photo.jpg", "/ben/photo.jpg") → 200
{{remaining}}("ana")                                     → 0
{{delete_file}}("/ana/photo.jpg")                        → 600
{{remaining}}("ana")                                     → 600
```
