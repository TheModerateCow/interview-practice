## Level 2: error budgets

Each service gets an error budget: the share of its requests that may fail. The on-call team wants to know how much budget is left and who is over it right now. Add:

| Method | Behaviour |
|---|---|
| `{{set_budget}}(service, budget_ppm) → bool` | Sets the service's budget (`0 <= {{budget_ppm}} <= 1 000 000`), replacing any earlier one. Returns `false` if the service doesn't exist. |
| `{{budget_left}}(service, start, end) → count or none` | How many more errors minutes `start..end` could have taken: the **allowed** errors, `total requests * budget_ppm / 1 000 000` rounded down, minus the errors they had. Negative when the budget is overspent. *None* if the service doesn't exist or has no budget. |
| `{{over_budget}}(end, window) → list of string` | Every service with a budget that is **over** it in the `window` minutes ending at `end` (minutes `end - window + 1 .. end`; minutes before 0 don't exist), as `"service:rate"` with the window's pooled rate in ppm. Highest rate first, comparing the ppm numbers shown; ties by name ascending. |

**Over budget** means strictly over: `errors * 1 000 000 > requests * budget_ppm` for the pooled totals. A window exactly on budget is not over, and a window with no requests never is. Budgets apply to every minute, including those recorded before the budget was set.

Names sort in plain string order (by character code, so `"C-svc"` comes before `"a-svc"`). Return an empty list when nothing matches.

### Example

```
(checkout has minutes 0-3: requests [100, 100, 100, 100], errors [0, 3, 1, 0])
(search   has minutes 0-3: requests [50, 50, 50, 50],     errors [2, 2, 0, 0])
{{set_budget}}("checkout", 10000)                    → true    (1%)
{{set_budget}}("search", 20000)                      → true
{{set_budget}}("payments", 5000)                     → false
{{budget_left}}("checkout", 0, 3)                    → 0       (4 allowed, 4 used)
{{budget_left}}("checkout", 1, 1)                    → -2
{{budget_left}}("search", 2, 3)                      → 2
{{over_budget}}(1, 2)                                → ["search:40000", "checkout:15000"]
{{over_budget}}(2, 3)                                → ["search:26666", "checkout:13333"]
{{over_budget}}(3, 2)                                → []
```
