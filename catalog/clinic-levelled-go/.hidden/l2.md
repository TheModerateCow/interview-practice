## Level 2: schedules, rankings and free slots

Reception wants a clinician's day at a glance, a workload ranking, and the next slot they can offer a caller. Add:

| Method | Behaviour |
|---|---|
| `Schedule(ts int, clinician string) []string` | The clinician's appointments that aren't cancelled, as `"id@start-end"`, earliest start first. |
| `BusiestClinicians(ts int, n int) []string` | Up to `n` clinicians as `"id:minutes"`, most minutes first; ties by id ascending. A clinician's **minutes** are the total length of their appointments that aren't cancelled. Clinicians with nothing booked are included (with `0`) if there's room. |
| `NextFree(ts int, clinician, kind string, after int) (int, bool)` | The earliest start at or after `after`, and never before `ts`, at which `Book(ts, clinician, …, kind, start)` would succeed: the clinician free and some room free for the type's whole length. `0, false` if the clinician or type doesn't exist, or the clinic has no rooms. |

Ids sort in plain Go string order. Return an empty, non-nil slice when nothing matches (or `n` is 0).

### Example

```
(dr-lee and dr-ng, one room room-1, types checkup 30 and consult 60)
Book(10, "dr-lee", "pat-1", "checkup", 600)       -> "appt1", true
Book(11, "dr-ng", "pat-2", "consult", 640)        -> "appt2", true
Schedule(12, "dr-lee")                            -> ["appt1@600-630"]
BusiestClinicians(13, 5)                          -> ["dr-ng:60", "dr-lee:30"]
NextFree(14, "dr-lee", "checkup", 560)            -> 560, true   (560-590 fits before appt1)
NextFree(15, "dr-lee", "checkup", 590)            -> 700, true   (dr-lee is free from 630, but room-1 is busy 640-700)
NextFree(16, "dr-lee", "checkup", 0)              -> 16, true
```
