## Level 2: waitlists

Popular classes fill up, and members want a fair shot at a freed spot. Add:

| Method | Behaviour |
|---|---|
| `{{join_waitlist}}(ts, {{class_id}}, member) → int` | Puts `member` at the back of the class's waitlist and returns their position (`1` = next in line). Returns `-1`, changing nothing, if the class doesn't exist, has started, still has a free spot (book it instead), or `member` already has a spot in it or is already waiting. |
| `{{waitlist}}(ts, {{class_id}}) → list of strings` | The waiting members, next in line first. An empty list if the class doesn't exist or nobody is waiting. |

New rules for what you already have:

- **Promotion.** When a member with a spot cancels, the first member on the waitlist leaves it and gets the spot straight away: the class stays full and the class shows in their `{{upcoming}}`.
- **Leaving the waitlist.** `{{cancel}}` by a waiting member removes them from the waitlist and returns `true`; everyone behind them moves up one place.
- Once a class has started, `{{cancel}}` still returns `false`, so nobody is promoted.

### Example

```
{{add_class}}(1, "spin", 600, 1)       → true
{{book}}(2, "spin", "maya")            → true
{{join_waitlist}}(3, "spin", "leo")    → 1
{{join_waitlist}}(4, "spin", "sam")    → 2
{{cancel}}(5, "spin", "maya")          → true    (leo gets the spot)
{{upcoming}}(6, "leo")                 → ["spin"]
{{waitlist}}(7, "spin")                → ["sam"]
```
