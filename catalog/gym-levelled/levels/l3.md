## Level 3: class credits

The gym starts charging for classes in credits that members buy in packs. Add:

| Method | Behaviour |
|---|---|
| `{{add_credits}}(ts, member, n) → int` | `member` buys `n` credits. Returns their new balance, or `-1`, changing nothing, if `n <= 0`. |
| `{{credits}}(ts, member) → int` | `member`'s balance; `0` for a member who never bought any. |
| `{{set_price}}(ts, {{class_id}}, price) → bool` | From now on, a spot in the class costs `price` credits. Returns `false` if the class doesn't exist, has started, or `price < 0`. Every class costs `0` until its price is set. |

New rules for what you already have:

- **Paying.** `{{book}}` takes the class's price from the member's balance, and returns `false`, changing nothing, if the balance is lower than the price.
- **Refunds.** A member who cancels a spot at least 60 minutes before the start (`start - ts >= 60`) gets back exactly what they paid for it, even if the price has changed since. A later cancellation refunds nothing, and so does not turning up.
- **Waitlist.** Joining is free; a promoted member pays the class's price when they get the spot. A waiting member whose balance is lower than the price is removed from the waitlist and the next one in line is tried.

### Example

```
{{add_class}}(1, "spin", 600, 10)     → true
{{set_price}}(2, "spin", 2)           → true
{{add_credits}}(3, "maya", 5)         → 5
{{book}}(4, "spin", "maya")           → true
{{credits}}(5, "maya")                → 3
{{cancel}}(540, "spin", "maya")       → true    (60 minutes before: refunded)
{{credits}}(541, "maya")              → 5
{{book}}(542, "spin", "maya")         → true
{{cancel}}(560, "spin", "maya")       → true    (40 minutes before: no refund)
{{credits}}(561, "maya")              → 3
```
