## Level 4: weekly series and history

Most classes repeat every week, and sometimes the gym has to call one off. Add:

| Method | Behaviour |
|---|---|
| `{{add_series}}(ts, {{series_id}}, {{first_start}}, capacity, weeks) → bool` | Schedules `weeks` classes with `capacity` spots each, with ids `"<{{series_id}}>-1"`, `"<{{series_id}}>-2"`, …: class `k` starts at `{{first_start}} + (k - 1) * 10080` (one week later each time). They are ordinary classes: book them, price them and cancel spots in them as before. Returns `false`, creating nothing, if the series id was already used, `weeks <= 0`, `capacity <= 0`, `{{first_start}} <= ts`, or any of those class ids already exists. |
| `{{cancel_class}}(ts, {{class_id}}) → bool` | The gym calls off a class. Every member with a spot gets back what they paid, however close to the start it is; the waitlist is cleared. Returns `false` if the class doesn't exist, has started, or is already called off. |
| `{{cancel_series}}(ts, {{series_id}}) → int` | Calls off every class of the series that hasn't started and isn't already called off, as `{{cancel_class}}` does. Returns how many it called off, or `-1` if the series doesn't exist. |
| `{{history}}(ts, member) → list of strings` | The ids of the classes `member` had a spot in when they started (`start <= ts`): earliest `start` first, ties by class id ascending. |

A called-off class is gone: `{{spots_left}}` returns `-1`, `{{book}}`, `{{cancel}}` and `{{set_price}}` return `false`, `{{join_waitlist}}` returns `-1`, `{{waitlist}}` is empty, and it appears in neither `{{upcoming}}` nor `{{history}}`. Its id stays taken, so `{{add_class}}` can't reuse it.

### Example

```
{{add_series}}(1, "yoga", 600, 2, 3)   → true    (yoga-1 at 600, yoga-2 at 10680, yoga-3 at 20760)
{{book}}(2, "yoga-1", "maya")          → true
{{add_credits}}(3, "maya", 2)          → 2
{{set_price}}(4, "yoga-3", 2)          → true
{{book}}(5, "yoga-3", "maya")          → true
{{cancel_series}}(700, "yoga")         → 2       (yoga-1 has started)
{{credits}}(701, "maya")               → 2
{{history}}(702, "maya")               → ["yoga-1"]
```
