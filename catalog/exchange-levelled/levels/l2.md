## Level 2: queue priority

Orders at the same price form a **queue**: the one that arrived first is first in line. Traders can change an order's size, and the exchange's rule is that making an order smaller keeps its place, while making it bigger costs it. Add:

| Method | Behaviour |
|---|---|
| `{{amend_order}}(order_id, qty) → bool` | Sets the resting order's size to `qty` shares (`qty >= 1`). A smaller or equal size keeps its place in the queue; a bigger size sends it to the **back** of the queue at its price, as if it had just arrived. Returns `false`, changing nothing, if no order with that id is resting. |
| `{{queue_at}}(price) → list of string` | The orders resting at `price`, first in line first, as `"id:shares"`. Empty if none. |
| `{{top_levels}}(n) → list of string` | Up to `n` price levels of the ask side, cheapest first, as `"price:shares:orders"` (the total shares and the number of orders resting at that price). Empty when the book is empty or `n` is 0. |

### Example

```
(a1 101x5, a2 100x3, a3 101x2, a4 103x4 were added in that order)
{{queue_at}}(101)                  → ["a1:5", "a3:2"]
{{amend_order}}("a1", 3)           → true    (smaller: keeps its place)
{{queue_at}}(101)                  → ["a1:3", "a3:2"]
{{amend_order}}("a1", 6)           → true    (bigger: back of the queue)
{{queue_at}}(101)                  → ["a3:2", "a1:6"]
{{depth_at}}(101)                  → 8
{{top_levels}}(2)                  → ["100:3:1", "101:8:2"]
{{amend_order}}("zz", 1)           → false
```
