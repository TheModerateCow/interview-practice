## Level 3: promo codes and abandoned carts

Marketing runs time-limited promo codes, and carts nobody touches are abandoned. Add to `Shop`:

| Method | Behaviour |
|---|---|
| `boolean addPromo(int ts, String code, int percentOff, long minTotalCents, int ttl)` | Creates a promo code worth `percentOff` percent off a cart, valid from `ts` until `ts + ttl`. Returns `false`, changing nothing, if `code` already exists (even expired), `percentOff` is outside 1–100, `minTotalCents < 0` or `ttl <= 0`. |
| `boolean applyPromo(int ts, String cartId, String code)` | Attaches `code` to the cart, replacing any code already attached. Returns `false`, changing nothing, if the cart doesn't exist or is empty, or the code doesn't exist or has expired. |
| `int activeCarts(int ts)` | How many carts exist right now and hold at least one item. |

**Discounts.** `cartTotal` and `checkout` use the discounted total: when the cart's attached code hasn't expired and the subtotal (price × quantity, summed) is at least the code's `minTotalCents`, the total is `subtotal - subtotal * percentOff / 100`, with the discount rounded **down** to whole cents. Otherwise the total is the subtotal. The code stays attached either way, so it starts or stops counting as the cart changes. A code created at `t` with `ttl` expires at `t + ttl`: from that timestamp on it gives no discount and can't be applied.

**Abandoned carts.** A successful `addToCart`, `removeFromCart` or `applyPromo` touches the cart. A cart last touched at `t` is abandoned at `t + 60`: from that timestamp on it's as if it never existed (`items` is empty, `cartTotal` is 0, `checkout` returns -1, `addToCart` starts a new empty cart). Reading a cart (`items`, `cartTotal`) doesn't touch it.

### Example

```
addProduct(1, "tee", 999, 10)
addPromo(2, "SAVE15", 15, 0, 100)
addToCart(3, "c1", "tee", 1)
applyPromo(4, "c1", "SAVE15") -> true
cartTotal(5, "c1")            -> 850    (999 - 149)
activeCarts(6)                -> 1
cartTotal(63, "c1")           -> 850
cartTotal(64, "c1")           -> 0      (last touched at 4, abandoned at 64)
activeCarts(65)               -> 0
```
