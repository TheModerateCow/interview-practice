## Level 2: cleaning up the log

The search team removes queries that shouldn't be suggested and folds misspellings into the right query. Add:

| Method | Behaviour |
|---|---|
| `{{delete_query}}({{query}}) → bool` | Removes `{{query}}` from the log entirely: its popularity becomes `0` and it is never suggested. `false`, changing nothing, if it isn't logged. Logging it again later starts from 1. |
| `{{merge_queries}}({{from}}, {{into}}) → int or none` | Moves all of `{{from}}`'s searches onto `{{into}}` and removes `{{from}}` from the log. `{{into}}` need not be logged yet (then this is a rename). Returns `{{into}}`'s new popularity. *None*, changing nothing, if `{{from}}` isn't logged or `{{from}}` and `{{into}}` are the same query. |

Suggestions always reflect the log as it is now.

### Example

```
(logged: shoes ×3, sheos ×2, shirt ×4)
{{suggest}}("sh")                             → "shirt"
{{merge_queries}}("sheos", "shoes")           → 5
{{suggest}}("sh")                             → "shoes"
{{popularity}}("sheos")                       → 0
{{suggest}}("she")                            → none
{{delete_query}}("shoes")                     → true
{{suggest}}("sh")                             → "shirt"
{{delete_query}}("shoes")                     → false
{{merge_queries}}("shirt", "shirt")           → none
{{merge_queries}}("boots", "shirt")           → none
{{merge_queries}}("shirt", "shirts")          → 4
{{suggest}}("shirt")                          → "shirts"
```
