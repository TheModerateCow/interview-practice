## Level 3: bulk imports and top lists

The box now shows a dropdown of several suggestions, and each night's search log arrives as one batch. The live site has tens of thousands of distinct queries; the dropdown is asked for on every keystroke while new searches keep being logged, so a dropdown request must not slow down as the log grows. Add:

| Method | Behaviour |
|---|---|
| `{{import_log}}({{log}}) → int` | Logs every search in `{{log}}` (in any order; repeats count, exactly as if each had been passed to `{{log_query}}`). Returns how many distinct queries are now logged. An empty `{{log}}` changes nothing. |
| `{{top_suggestions}}({{prefix}}, {{k}}) → list of string` | Up to `{{k}}` logged queries that start with `{{prefix}}`, as `"query:popularity"`, best first: most popular, ties alphabetical, so the first entry is always `{{suggest}}`'s answer. An empty list when nothing matches or `{{k}}` is `0`. |

Deleted and merged-away queries never appear; every list reflects all logging, imports, deletes and merges so far.

### Example

```
{{import_log}}(["shoes", "shirts", "shoes", "shirt", "shirts", "shorts", "shirts"])   → 4
{{top_suggestions}}("sh", 3)                  → ["shirts:3", "shoes:2", "shirt:1"]
{{top_suggestions}}("shi", 5)                 → ["shirts:3", "shirt:1"]
{{log_query}}("shirt")                        → 2
{{log_query}}("shirt")                        → 3
{{top_suggestions}}("shi", 5)                 → ["shirt:3", "shirts:3"]
{{top_suggestions}}("x", 2)                   → []
{{top_suggestions}}("sh", 0)                  → []
```
