## Level 3: joining tables

Large parties don't fit any single table, but some tables stand next to each other and can be pushed together. Add:

| Method | Behaviour |
|---|---|
| `{{link_tables}}(ts, table_a, table_b) → bool` | Records that the two tables stand side by side and can be joined. Links have no direction: linking `"T2"` and `"T1"` is the same link as `"T1"` and `"T2"`. A table can be linked to several others. Returns `false` if either table doesn't exist, they're the same table, or they're already linked. |

**Joined tables.** When no single table fits, the booking rule (for `{{book}}`, `{{join_waitlist}}` and seating from the waitlist) tries a join: two linked tables, both free at that slot, whose seats add up to at least `size`. It picks the join with the fewest seats in total; ties go to the smaller lower table id, then the smaller higher id. A single table that fits always wins over a join, even a join with fewer seats. Only two tables are ever joined.

The reservation holds both tables: `{{table_of}}` returns `"lower+higher"` (e.g. `"T1+T2"`, lower id first), `{{party_at}}` shows the party on both, and neither appears in `{{free_tables}}`. The join exists only for that reservation: when it's cancelled, both tables are free on their own again and the waitlist is walked as usual.

### Example

```
{{add_table}}(1, "T1", 2); {{add_table}}(1, "T2", 4); {{add_table}}(1, "T3", 4)
{{link_tables}}(2, "T1", "T2")       → true
{{link_tables}}(3, "T2", "T3")       → true
{{book}}(4, "maya", 7, 1140)         → "r1"
{{table_of}}(5, "r1")                → "T2+T3"   (T1+T2 has only 6 seats)
{{party_at}}(6, "T3", 1140)          → "maya"
{{book}}(7, "leo", 5, 1140)          → ""        (T2 is taken)
{{cancel}}(8, "r1")                  → true
{{book}}(9, "leo", 5, 1140)          → "r2"
{{table_of}}(10, "r2")               → "T1+T2"   (6 seats beats 8)
```
