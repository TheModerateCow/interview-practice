## Level 2: profile changes and agendas

People relocate, switch shifts, and want to see what's already booked. Add:

| Method | Behaviour |
|---|---|
| `{{set_offset}}({{id}}, {{offset}}) → bool` | The attendee moves to another time zone. Their working hours stay the same in **local** time, so they move in UTC; their busy blocks stay where they are in UTC. `false` if the attendee doesn't exist. |
| `{{set_hours}}({{id}}, {{work_start}}, {{work_end}}) → bool` | Replaces the attendee's working hours (same rules as in `{{add_attendee}}`). `false` if the attendee doesn't exist. |
| `{{agenda}}({{id}}, {{from}}, {{to}}) → list of string` | The attendee's busy blocks that overlap `[{{from}}, {{to}})` (`{{from}} < {{to}}`), as `"busyId:start-end"`. A block overlaps if it covers at least one minute of the range: one ending exactly at `{{from}}` or starting exactly at `{{to}}` doesn't. Ordered by start, then by end, then oldest block first. An empty list for an unknown attendee or when nothing overlaps. |

### Example

```
(ana: offset 0, hours 540-1020; busy1 600-660, busy2 480-720, busy3 900-960)
{{agenda}}("ana", 600, 900)                   → ["busy2:480-720", "busy1:600-660"]
{{set_offset}}("ana", -300)                   → true     (09:00 local is now UTC 840)
{{is_free}}("ana", 600)                       → false
{{is_free}}("ana", 840)                       → true
{{is_free}}("ana", 900)                       → false    (busy3)
{{set_hours}}("ana", 1320, 360)               → true     (22:00-06:00 local = UTC 180-660)
{{is_free}}("ana", 179)                       → false
{{is_free}}("ana", 180)                       → true
{{is_free}}("ana", 480)                       → false    (busy2)
{{set_offset}}("bob", 0)                      → false
```
