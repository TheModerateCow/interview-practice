## Level 2: daily settlement

Customers get a statement for each day, and the operations team wants to see which batteries earned the most. Add:

| Method | Behaviour |
|---|---|
| `{{day_profit}}(id, day) → pence or none` | The battery's net cash from its actions on that day: what its discharges earned (after wear) minus what its charges paid. `0` for a day it did nothing (including a day with no tariff); *none* for an unknown id. |
| `{{top_earners}}(day, n) → list of string` | Up to `n` registered batteries as `"id:profit"`, by `{{day_profit}}` on that day, largest first; ties by id ascending. Batteries that did nothing that day are included (with `0`) if there's room, and so are ones that lost money. |

An action counts on the day it names. Energy charged on one day and sold on another shows as a cost on the first day and earnings on the second. Refused actions never count.

Ids sort in plain string order (by code unit, so `"HOME-B"` comes before `"home-a"`). Return an empty list when `n` is 0.

### Example

```
(home-a, home-b and home-c are registered with capacity 2 and wear 0;
 day 1's tariff is [10, 30, 20], day 2's is [25, 5])
{{charge}}("home-a", 1, 0)                    → 1
{{discharge}}("home-a", 1, 1)                 → 0
{{charge}}("home-b", 1, 0)                    → 1
{{charge}}("home-b", 1, 2)                    → 2
{{discharge}}("home-b", 2, 0)                 → 1
{{discharge}}("home-a", 2, 1)                 → none     (home-a is empty)
{{day_profit}}("home-b", 1)                   → -30
{{day_profit}}("home-b", 2)                   → 25
{{top_earners}}(1, 2)                         → ["home-a:20", "home-c:0"]
{{top_earners}}(2, 5)                         → ["home-b:25", "home-a:0", "home-c:0"]
```
