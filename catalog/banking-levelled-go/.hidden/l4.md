## Level 4: merges and balance history

Customers who consolidate their accounts get them merged, and auditors ask "what was this account's balance back then?". Add:

| Method | Behaviour |
|---|---|
| `MergeAccounts(ts int, keep, absorb string) bool` | Folds `absorb` into `keep`, then closes `absorb`. Returns `false`, changing nothing, if either account doesn't exist or they're the same account. |
| `BalanceAt(ts int, id string, atTs int) (int, bool)` | The balance account `id` had right after everything that happened at or before `atTs` (`atTs <= ts`), and `true`; `0, false` if no account with that id was open at `atTs`. |

**What a merge moves.** `keep`'s balance grows by `absorb`'s balance, and its spending (for `TopSpenders`) grows by `absorb`'s spending. Every **pending** payment of `absorb` now draws on `keep`, keeping its id and due time; from then on it can be cancelled only through `keep`. The merge itself isn't spending.

**After a merge** `absorb` no longer exists: every method treats it as an id that was never opened, and it's left out of the rankings. The id can be opened again later as a brand-new, empty account with no spending.

**History.** `BalanceAt` answers for whichever account held that id at `atTs`: before a merge, an absorbed account's own balance; between the merge and a reopening, nothing. A scheduled payment changes the balance at its **due time**, even if the bank only noticed it at a later call.

### Example

```
(acc-a is open with 500, acc-b with 200, both deposited by time 4)
SchedulePayment(5, "acc-b", 300, 15)       -> "pay1", true    (due at 20)
Withdraw(6, "acc-b", 50)                   -> 150, true
MergeAccounts(10, "acc-a", "acc-b")        -> true
Balance(11, "acc-a")                       -> 650, true
Balance(12, "acc-b")                       -> 0, false
TopSpenders(13, 3)                         -> ["acc-a:50"]
Balance(25, "acc-a")                       -> 350, true       (pay1 ran at 20, from acc-a)
BalanceAt(26, "acc-b", 8)                  -> 150, true
BalanceAt(27, "acc-b", 10)                 -> 0, false
BalanceAt(28, "acc-a", 19)                 -> 650, true
BalanceAt(29, "acc-a", 20)                 -> 350, true
```
