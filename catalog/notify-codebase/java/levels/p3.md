## Phase 3: a chatty integration

A partner's integration sends every user on it a notification every few seconds, all day; most of them end up held by the hourly caps. On busy days each `send` to those users gets slower and slower: by the fourth day it takes tens of microseconds per call and climbing, and the fan-out falls behind. Five days of that traffic for one user (about 86,000 sends) has to go through in **under 2.5 seconds**.

Find the bottleneck and fix it. Behaviour must not change: every phase 1 and phase 2 test must still pass, and every send must get the same result.
