## Level 2: shelf and reader queries

The desk wants to see what's on the shelf, what each member has out, and which titles are in demand. Add:

| Method | Behaviour |
|---|---|
| `{{available}}(ts, title) → int` | How many copies of `title` are on the shelf (not on loan). `0` for a title the library doesn't own. |
| `{{loans_of}}(ts, member_id) → list of strings` | The copy ids the member has on loan, in ascending order. An empty list if none, or if the member is unknown. |
| `{{popular}}(ts, n) → list of strings` | Up to `n` titles as `"title(checkouts)"`, where `checkouts` is the number of successful `{{checkout}}` calls for any copy of that title so far: most checkouts first, ties by title ascending. Titles never checked out are left out. An empty list if nothing has been lent yet. |

A failed `{{checkout}}` is not a checkout. Checkouts stay counted after the copy is returned.

### Example

```
{{add_member}}(1, "ana"); {{add_member}}(2, "bo")
{{add_copy}}(3, "D-1", "Dune"); {{add_copy}}(4, "D-2", "Dune"); {{add_copy}}(5, "E-1", "Emma")
{{checkout}}(6, "ana", "Emma"); {{checkout}}(7, "ana", "Dune"); {{checkout}}(8, "bo", "Dune")
{{available}}(9, "Dune")   → 0
{{available}}(10, "Emma")  → 0
{{loans_of}}(11, "ana")     → ["D-1", "E-1"]
{{return_copy}}(12, "E-1"); {{checkout}}(13, "bo", "Emma")
{{popular}}(14, 5)         → ["Dune(2)", "Emma(2)"]
{{popular}}(15, 1)         → ["Dune(2)"]
```
