## Level 3: arrivals and departures

Guests now check in and out, and the desk stops holding rooms for people who never arrive. Add:

| Method | Behaviour |
|---|---|
| `{{check_in}}(day, booking_id)` | The guest arrives. Only allowed on the booking's first night (`check_in` day). Returns `false` if the booking doesn't exist, is cancelled, is already checked in, or `day` isn't its `check_in` day. |
| `{{check_out}}(day, booking_id)` | The guest leaves on `day` and pays. Returns the amount charged: the nights actually stayed (`min(day, check_out) - check_in`, but at least 1) times the nightly rate. Returns `-1` if the booking doesn't exist or isn't checked in (never arrived, or already checked out). |

New rules for what you already have:

- **No booking in the past.** `{{book}}` returns `""` and `{{available_rooms}}` leaves a room out when `check_in < day`.
- **No-shows.** A booking that isn't checked in by the end of its `check_in` day is released: from day `check_in + 1` on it behaves like a cancelled booking. Its nights can be booked again, `{{cost}}` returns `-1`, `{{cancel}}` and `{{check_in}}` return `false`, and it doesn't count in `{{top_guests}}`.
- **Checked-in bookings** can't be cancelled.
- **Leaving early** frees the remaining nights. After `{{check_out}}`, the booking covers only the nights charged: `{{cost}}` returns the amount charged and `{{top_guests}}` counts only those nights.

### Example

```
add_room(1, "201", "single", 8000)
book(2, "maya", "201", 10, 15)  -> "b1"
check_in(10, "b1")              -> true
check_out(12, "b1")             -> 16000   (2 nights)
book(13, "leo", "201", 13, 15)  -> "b2"
cost(16, "b2")                  -> -1      (leo never checked in)
```
