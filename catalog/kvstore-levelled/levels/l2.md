## Level 2: scans

Operators want to see a whole record, and to find records by naming convention. Add:

| Method | Behaviour |
|---|---|
| `{{scan}}({{ts}}, {{key}}) → list of string` | Every field of `{{key}}` as `"field=value"`, sorted by field name ascending. An empty list if the record doesn't exist. |
| `{{scan_prefix}}({{ts}}, {{key}}, {{prefix}}) → list of string` | The same, but only fields whose name **starts with** `{{prefix}}`. An empty prefix matches every field. |
| `{{list_keys}}({{ts}}, {{prefix}}) → list of string` | Keys of every record that starts with `{{prefix}}` and has at least one field, ascending. |

Sorting is plain string order (byte by byte), so `"env"` comes before `"env.HOST"`. Return an empty list when nothing matches.

### Example

```
{{set}}(1, "svc-api", "image", "v1"); {{set}}(2, "svc-api", "env.PORT", "8080"); {{set}}(3, "svc-api", "env.HOST", "0.0.0.0")
{{set}}(4, "svc-web", "image", "w1"); {{set}}(5, "db-main", "size", "large")
{{scan}}(6, "svc-api")                → ["env.HOST=0.0.0.0", "env.PORT=8080", "image=v1"]
{{scan_prefix}}(7, "svc-api", "env.")  → ["env.HOST=0.0.0.0", "env.PORT=8080"]
{{list_keys}}(8, "svc-")               → ["svc-api", "svc-web"]
```
