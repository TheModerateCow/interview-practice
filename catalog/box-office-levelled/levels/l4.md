## Level 4: history

Support needs to answer "how many tickets did this person have on Tuesday?". Add:

| Method | Behaviour |
|---|---|
| `{{owned_at}}(ts, event_id, buyer, at_ts) → int` | How many tickets `buyer` owned for `event_id` after every operation with a timestamp at or before `at_ts`. `-1` if the event doesn't exist now; `0` for a time before the event was created. |
| `{{sold_at}}(ts, event_id, at_ts) → int` | The same, summed over all buyers of `event_id`. `-1` if the event doesn't exist now. |

Buying, refunding and confirming a hold change what is owned, at the time of that call. A hold that was never confirmed was never owned.

### Example

```
{{create_event}}(1, "jazz-night", 10)
{{buy}}(5, "jazz-night", "maya", 3)
{{refund}}(9, "jazz-night", "maya", 1)
{{owned_at}}(20, "jazz-night", "maya", 4) → 0
{{owned_at}}(20, "jazz-night", "maya", 5) → 3
{{owned_at}}(20, "jazz-night", "maya", 9) → 2
```
