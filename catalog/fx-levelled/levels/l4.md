## Level 4: standing conversion orders

Customers want to say "convert 2000 USD into EUR as soon as the rate reaches 0.95" and walk away. Add:

| Method | Behaviour |
|---|---|
| `{{place_order}}(ts, {{wallet_id}}, source, target, amount, {{min_rate}}) → string` | Places a standing order to convert `amount` of `source` into `target` once the `source → target` rate is at least `{{min_rate}}`, and returns its id. Ids are `"o1"`, `"o2"`, `"o3"`, … in order, counted across the whole app; a failed call uses no id. Returns `""` if the wallet doesn't exist, either code isn't a currency, `source == target`, `amount <= 0` or `{{min_rate}} <= 0`. The wallet doesn't need to hold `amount` yet, and nothing is set aside. |
| `{{cancel_order}}(ts, {{order_id}}) → bool` | Cancels an open order. Returns `false` if the order doesn't exist or isn't open. |
| `{{order_status}}(ts, {{order_id}}) → string` | `"open"`, `"filled:<credited>"` (for example `"filled:1901"`, the amount of `target` it credited) or `"cancelled"`. `""` for an id that was never issued. |

**When orders run.** Orders are checked only when `{{set_rate}}` succeeds, and only the open orders for exactly that `source → target` pair; placing an order never runs it, even if the current rate already qualifies. Every one of those orders whose `{{min_rate}}` is at most the new rate runs, in the order the orders were placed, each right after the rate is recorded:

- it converts exactly as `{{convert}}` would at that moment, at the **new** rate (fee and rounding included), and becomes `"filled:<credited>"`;
- if `{{convert}}` would return `-1` (for example, an earlier order took the money), it takes nothing and becomes `"cancelled"`. A cancelled or filled order never runs again.

### Example

```
{{open_wallet}}(1, "ana"); {{deposit}}(2, "ana", "USD", 5000)
{{set_rate}}(3, "USD", "EUR", 900000)
{{place_order}}(4, "ana", "USD", "EUR", 2000, 950000)   → "o1"
{{place_order}}(5, "ana", "USD", "EUR", 4000, 920000)   → "o2"
{{set_rate}}(6, "USD", "EUR", 960000)                   → true
{{order_status}}(7, "o1")                               → "filled:1901"
{{order_status}}(8, "o2")                               → "cancelled"   (only 3000 USD left)
{{balance}}(9, "ana", "EUR")                            → 1901
{{cancel_order}}(10, "o1")                              → false
```
