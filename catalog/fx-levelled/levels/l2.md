## Level 2: exchange rates and conversions

The treasury desk now publishes exchange rates, customers can convert between currencies for a fee, and they can send money to each other. Add:

| Method | Behaviour |
|---|---|
| `{{set_rate}}(ts, source, target, rate) → bool` | Publishes the rate for converting `source` into `target`, replacing the pair's previous rate. Returns `false`, changing nothing, if either code isn't a currency, `source == target`, or `rate <= 0`. |
| `{{quote}}(ts, source, target, amount) → int` | How much of `target` converting `amount` of `source` would credit right now (formula below), without moving any money. The result can be `0` for a tiny amount. Returns `-1` if either code isn't a currency, `source == target`, `amount <= 0`, or the pair has no rate. |
| `{{convert}}(ts, {{wallet_id}}, source, target, amount) → int` | Takes `amount` of `source` out of the wallet, credits the quoted amount of `target`, and returns the amount credited. Returns `-1`, changing nothing, if the wallet doesn't exist, `{{quote}}` would return `-1` or `0`, or the wallet holds less than `amount` of `source`. |
| `{{transfer}}(ts, sender, receiver, currency, amount) → bool` | Moves `amount` of `currency` from wallet `sender` to wallet `receiver`, with no fee. Returns `false`, changing nothing, if either wallet doesn't exist, `sender == receiver`, `amount <= 0`, or the sender holds less than `amount` of `currency`. |

**Rates** are integers scaled by 1 000 000, between minor units: a `USD → EUR` rate of `920000` means 1 minor unit of USD is worth 0.92 minor units of EUR. A rate is one-way: publishing `USD → EUR` says nothing about `EUR → USD`.

**The fee and rounding.** Every conversion keeps a 1% fee. The amount credited is

```
amount × rate × 99 / 100 000 000
```

rounded **once**, to the nearest whole minor unit, with an exact half rounding **up** (49.5 → 50). Don't round the fee or the gross amount separately. Amounts and rates are small enough that `amount × rate × 100` fits in a signed 64-bit integer.

### Example

```
{{open_wallet}}(1, "ana"); {{deposit}}(2, "ana", "USD", 10000)
{{set_rate}}(3, "USD", "EUR", 920000)          → true
{{quote}}(4, "USD", "EUR", 1000)               → 911     (910.8 rounds to 911)
{{convert}}(5, "ana", "USD", "EUR", 1000)      → 911
{{balance}}(6, "ana", "USD")                   → 9000
{{quote}}(7, "EUR", "USD", 100)                → -1      (no EUR → USD rate)
{{open_wallet}}(8, "bob")
{{transfer}}(9, "ana", "bob", "EUR", 500)      → true
{{holdings}}(10, "bob")                        → ["EUR:500"]
```
