## Level 4: history

Support needs to answer "how many tickets did this person have on Tuesday?". Add:

| Method | Behaviour |
|---|---|
| `OwnedAt(ts int, eventID, buyer string, atTs int) int` | How many tickets `buyer` owned for `eventID` after every operation with a timestamp at or before `atTs`. `-1` if the event doesn't exist now; `0` for a time before the event was created. |
| `SoldAt(ts int, eventID string, atTs int) int` | The same, summed over all buyers of `eventID`. `-1` if the event doesn't exist now. |

Buying, refunding and confirming a hold change what is owned, at the time of that call. A hold that was never confirmed was never owned.

### Example

```
CreateEvent(1, "jazz-night", 10)
Buy(5, "jazz-night", "maya", 3)
Refund(9, "jazz-night", "maya", 1)
OwnedAt(20, "jazz-night", "maya", 4) -> 0
OwnedAt(20, "jazz-night", "maya", 5) -> 3
OwnedAt(20, "jazz-night", "maya", 9) -> 2
```
