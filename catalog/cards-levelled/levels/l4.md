## Level 4: spending controls

Customers can cap what a card spends per merchant category each day, and freeze a card they've misplaced. Add:

| Method | Behaviour |
|---|---|
| `{{set_category_limit}}(day, card_id, category, limit)` | From now on the card may spend at most `limit` per day in `category`, replacing any earlier limit for that category. A limit of `0` blocks the category. Returns `false`, changing nothing, if the card doesn't exist or `limit < 0`. |
| `{{freeze}}(day, card_id)` | Freezes the card. Returns `false` if the card doesn't exist or is already frozen. |
| `{{unfreeze}}(day, card_id)` | Unfreezes it. Returns `false` if the card doesn't exist or isn't frozen. |

**Category limits.** `{{authorize}}` also declines when the card has a limit for `category` and the day's spending in that category plus `amount` would be more than the limit (reaching it exactly is fine). The day's spending in a category is taken over the card's authorisations **approved today** in that category:

- an open one counts its authorised amount;
- a captured one counts the amount captured;
- a voided one counts nothing.

Refunds don't give back room under the limit. Authorisations approved today before the limit was set count too. Categories without a limit, and other cards, aren't affected.

**Frozen cards.** `{{authorize}}` declines every request on a frozen card. Everything already approved carries on as normal: `{{capture}}`, `{{void_auth}}` and `{{refund}}` still work, and holds still expire.

### Example

```
issue_card(1, "c1", 50000)
set_category_limit(1, "c1", "gambling", 10000)  -> true
authorize(2, "c1", "gambling", 6000)            -> "a1"
authorize(2, "c1", "gambling", 5000)            -> ""      (11000 today)
authorize(2, "c1", "grocery", 5000)             -> "a2"
authorize(3, "c1", "gambling", 5000)            -> "a3"    (a new day)
freeze(4, "c1")                                 -> true
authorize(4, "c1", "grocery", 100)              -> ""
capture(4, "a1", 6000)                          -> true
unfreeze(5, "c1")                               -> true
authorize(5, "c1", "grocery", 100)              -> "a4"
```
