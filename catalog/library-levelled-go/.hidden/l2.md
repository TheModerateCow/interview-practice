## Level 2: shelf and reader queries

The desk wants to see what's on the shelf, what each member has out, and which titles are in demand. Add:

| Method | Behaviour |
|---|---|
| `Available(ts int, title string) int` | How many copies of `title` are on the shelf (not on loan). `0` for a title the library doesn't own. |
| `LoansOf(ts int, memberID string) []string` | The copy ids the member has on loan, in ascending order. An empty list if none, or if the member is unknown. |
| `Popular(ts int, n int) []string` | Up to `n` titles as `"title(checkouts)"`, where `checkouts` is the number of successful `Checkout` calls for any copy of that title so far: most checkouts first, ties by title ascending. Titles never checked out are left out. An empty list if nothing has been lent yet. |

A failed `Checkout` is not a checkout. Checkouts stay counted after the copy is returned.

### Example

```
AddMember(1, "ana"); AddMember(2, "bo")
AddCopy(3, "D-1", "Dune"); AddCopy(4, "D-2", "Dune"); AddCopy(5, "E-1", "Emma")
Checkout(6, "ana", "Emma"); Checkout(7, "ana", "Dune"); Checkout(8, "bo", "Dune")
Available(9, "Dune")   -> 0
Available(10, "Emma")  -> 0
LoansOf(11, "ana")     -> ["D-1", "E-1"]
Return(12, "E-1"); Checkout(13, "bo", "Emma")
Popular(14, 5)         -> ["Dune(2)", "Emma(2)"]
Popular(15, 1)         -> ["Dune(2)"]
```
