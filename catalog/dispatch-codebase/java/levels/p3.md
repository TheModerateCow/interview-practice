## Phase 3: dinner rush

Friday dinner rush, one zone: about 280 couriers on shift (10 orders each at most) and 2,800 orders waiting. A single `dispatchPending` tick takes several seconds, and hand-assigning the same backlog one `assign` at a time is just as slow. The dispatch loop runs every minute, so a tick has to finish in well under half a second.

Find the bottleneck and fix it. Behaviour must not change: every phase 1 and phase 2 test must still pass, and the same orders must go to the same couriers.
