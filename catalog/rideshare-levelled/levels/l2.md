## Level 2: dispatch and trips

Now drivers actually go and pick riders up. Add:

| Method | Behaviour |
|---|---|
| `{{dispatch}}(ts, rider) → driver id or none` | Sends the driver `{{nearest_driver}}` would pick to the rider. The rider stops waiting and the driver goes **on a trip**. Returns the driver's id, or *none*, changing nothing, if `{{nearest_driver}}` would return *none*. |
| `{{complete_trip}}(ts, driver, km) → bool` | The driver drops their rider off at marker `km` and is idle there again. Returns `false`, changing nothing, if the driver isn't on a trip. |
| `{{idle_between}}(ts, lo, hi) → list of string` | Every idle driver at a marker from `lo` to `hi` inclusive, as `"id:km"`, lowest marker first; same marker by id (plain string order). An empty list when there are none (or `lo > hi`). |

**On a trip.** A driver on a trip is still on shift but not idle: `{{nearest_driver}}`, `{{dispatch}}` and `{{idle_between}}` skip them, `{{move_driver}}` and `{{remove_driver}}` return `false`, and `{{add_driver}}` with their id returns `false`. A rider who was picked up is no longer waiting, so their id can be added again as a new rider.

### Example

```
(d1 idle at 10, d2 at 40; r1 waiting at 12, r2 at 35)
{{dispatch}}(5, "r1")                         → "d1"
{{dispatch}}(6, "r1")                         → none     (r1 was picked up)
{{idle_between}}(7, 0, 100)                   → ["d2:40"]
{{dispatch}}(8, "r2")                         → "d2"
{{add_rider}}(9, "r3", 20)                    → true
{{dispatch}}(10, "r3")                        → none     (nobody idle)
{{complete_trip}}(11, "d1", 50)               → true
{{complete_trip}}(12, "d1", 60)               → false    (d1 is idle now)
{{idle_between}}(13, 0, 100)                  → ["d1:50"]
{{dispatch}}(14, "r3")                        → "d1"
```
