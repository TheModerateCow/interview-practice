## Level 2: the upgrade waitlist

Economy passengers on this flight can ask to be upgraded for their trip. A request that fits is confirmed on the spot; one that doesn't waits until the desk works through the waitlist. Add:

| Method | Behaviour |
|---|---|
| `{{request_upgrade}}({{passenger}}, {{board}}, {{alight}}) → string` | `"upgraded"` if every leg of the trip has a free seat: the passenger takes a seat on each leg, just like a booking. Otherwise `"waitlisted"`: the passenger takes no seat and joins the **end** of the waitlist. Returns `""`, changing nothing, if the trip isn't valid or the passenger already holds a seat or is waitlisted. |
| `{{status}}({{passenger}}) → string` | `"booked"` (seated by `{{book}}`), `"upgraded"` (seated by an upgrade), `"waitlisted"`, or `""` for anyone else. |
| `{{promote}}() → list of string` | Works through the waitlist **oldest request first**. Each waiting passenger whose whole trip now fits is seated at once (status `"upgraded"`) before the next one is checked; the others keep their place. Returns the passengers seated by this call, in that order (an empty list if none). |

**Changes to level 1.** `{{book}}` also returns `false` for a waitlisted passenger. `{{cancel}}` works for everyone the desk knows: an upgraded passenger gives up their seat like a booked one, and a waitlisted passenger leaves the waitlist (they held no seat). Either way the passenger is then unknown: `{{status}}` gives `""`, and a new request joins the end of the waitlist.

**Nothing moves on its own.** Seats freed by a cancellation stay free until `{{promote}}` is called; a `{{book}}` or a fitting `{{request_upgrade}}` in between may take them.

### Example

```
{{new Flight}}([1, 1, 1, 1])
{{book}}("ana", 1, 3)               → true
{{request_upgrade}}("ben", 0, 4)    → "waitlisted"
{{request_upgrade}}("cy", 3, 4)     → "upgraded"
{{request_upgrade}}("dee", 0, 2)    → "waitlisted"
{{request_upgrade}}("ana", 0, 1)    → ""             (ana holds a seat)
{{cancel}}("ana")                   → true
{{status}}("ben")                   → "waitlisted"   (nothing moves until promote)
{{promote}}()                       → ["dee"]        (ben still needs leg 3, which cy holds)
{{status}}("dee")                   → "upgraded"
{{cancel}}("ben")                   → true           (leaves the waitlist)
{{status}}("ben")                   → ""
{{promote}}()                       → []
```
