## Level 2: occupancy and regulars

The operators want to see how full each size is and who parks most often. Add:

| Method | Behaviour |
|---|---|
| `{{free_spots}}(ts, size)` | How many spots of exactly `size` are free. `-1` if `size` is invalid. |
| `{{top_visitors}}(ts, n)` | Up to `n` plates as `"plate(visits)"`, where `visits` is the number of successful `{{park}}` calls for that plate so far: most visits first, ties by plate ascending. An empty list if nobody has parked yet. |

A failed `{{park}}` is not a visit. Visits stay counted after the vehicle leaves.

### Example

```
{{add_spot}}(1, "A1", "small"); {{add_spot}}(2, "B1", "medium"); {{add_spot}}(3, "C1", "large")
{{park}}(4, "KX-101", "small"); {{park}}(5, "VN-220", "small")
{{free_spots}}(6, "small")  -> 0
{{free_spots}}(7, "medium") -> 0
{{free_spots}}(8, "large")  -> 1
{{leave}}(9, "KX-101"); {{park}}(10, "KX-101", "small")
{{top_visitors}}(11, 5)     -> ["KX-101(2)", "VN-220(1)"]
```
