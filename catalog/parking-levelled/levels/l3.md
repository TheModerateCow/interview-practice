## Level 3: reservations

Drivers can book a spot shortly before they arrive. Add:

| Method | Behaviour |
|---|---|
| `{{reserve}}(ts, plate, size, ttl)` | Reserves for `plate` the spot `{{park}}` would pick right now for a vehicle of `size`, and returns its id. Returns `""`, changing nothing, if `size` is invalid, `ttl <= 0`, `plate` is parked, `plate` already has a live reservation, or no free spot fits. |
| `{{cancel}}(ts, plate)` | Drops `plate`'s live reservation. Returns `false` if it has none. |

A reservation made at time `t` with `ttl` expires at `t + ttl`: from that timestamp on it holds nothing and can't be cancelled.

While a reservation is live, its spot is **not free**: `{{free_spots}}` doesn't count it, and other vehicles' `{{park}}` and `{{reserve}}` skip it. When the plate itself calls `{{park}}` while its reservation is live, it goes into its reserved spot (even if a better spot has opened up since) and the reservation is used up. A plate whose reservation expired parks like anyone else. A reservation is not a visit; the park is.

### Example

```
{{add_spot}}(1, "A1", "small"); {{add_spot}}(2, "A2", "small")
{{reserve}}(10, "KX-101", "small", 30) -> "A1"
{{park}}(12, "VN-220", "small")        -> "A2"   (A1 is reserved)
{{free_spots}}(13, "small")             -> 0
{{park}}(14, "TR-900", "small")        -> ""
{{park}}(20, "KX-101", "small")        -> "A1"   (its reserved spot)
{{leave}}(22, "VN-220")                -> true
{{reserve}}(23, "TR-900", "small", 5)  -> "A2"
{{free_spots}}(27, "small")             -> 0
{{free_spots}}(28, "small")             -> 1      (expired at 28)
```
