## Level 4: the review queue

Transactions sent to review now wait in a queue, oldest first, for an analyst to approve or decline them (in any order). A decline means the card is probably stolen, so it's blocked for a while. Add:

| Method | Behaviour |
|---|---|
| `{{pending_reviews}}({{ts}}) → list of string` | The ids of every transaction whose decision is still `"review"`, oldest first (in the order they were screened). |
| `{{approve_review}}({{ts}}, {{txn_id}}) → bool` | The analyst approves a pending review: its decision becomes `"approve"`. Returns `false`, changing nothing, if the transaction isn't a pending review. |
| `{{decline_review}}({{ts}}, {{txn_id}}, {{block_for}}) → bool` | The analyst declines a pending review: its decision becomes `"decline"`, and its card is blocked until `{{ts}} + {{block_for}}`. Returns `false`, changing nothing, if the transaction isn't a pending review or `{{block_for}} <= 0`. |

After an analyst's verdict, `{{decision}}` returns it and `{{explain}}` returns `"analyst"`.

**Temporary blocks.** The block from `{{decline_review}}` is the card's blocklist entry `"block:card:<card>"`, with priority 0, that **expires**: from time `{{ts}} + {{block_for}}` on, it's gone (it no longer matches, `{{unblock}}` and `{{set_priority}}` return `false`, and `{{block}}` can block the card again). Until then it's an ordinary entry: `{{block}}` returns `false` for it, `{{unblock}}` removes it early, `{{set_priority}}` changes its priority, and a higher-priority allowlist entry overrides it.

- If the card is already blocked **permanently** (by `{{block}}`), that entry stays as it is and never expires.
- If it's already blocked **temporarily**, the block keeps its priority and lasts until the later of its current end and `{{ts}} + {{block_for}}`.

### Example

```
{{add_velocity_rule}}(1, "v-amount", "amount", 50000, 60)  → true
{{screen}}(10, "t1", "4111", "m-tv", 80000, "GB")          → "review"
{{screen}}(20, "t2", "5500", "m-tv", 70000, "GB")          → "review"
{{pending_reviews}}(30)                                    → ["t1", "t2"]
{{decline_review}}(40, "t1", 100)                          → true    (4111 blocked until 140)
{{decision}}(41, "t1")                                     → "decline"
{{explain}}(41, "t1")                                      → "analyst"
{{screen}}(50, "t3", "4111", "m-books", 1000, "GB")        → "decline"
{{explain}}(51, "t3")                                      → "block:card:4111"
{{approve_review}}(60, "t2")                               → true
{{pending_reviews}}(70)                                    → []
{{screen}}(140, "t4", "4111", "m-books", 1000, "GB")       → "approve"
```
