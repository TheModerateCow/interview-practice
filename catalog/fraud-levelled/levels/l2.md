## Level 2: velocity rules

Fraudsters who get hold of a card spend fast. The risk team wants rules that send a card's transaction to manual review when the card is used too often, or for too much, in a short time. Add:

| Method | Behaviour |
|---|---|
| `{{add_velocity_rule}}({{ts}}, {{rule_id}}, {{metric}}, {{limit}}, {{window}}) → bool` | Adds a rule that fires when a card's transactions within the last `{{window}}` seconds number more than `{{limit}}` (`{{metric}}` `"count"`) or total more than `{{limit}}` cents (`{{metric}}` `"amount"`). Returns `false`, changing nothing, if a rule `{{rule_id}}` exists, `{{metric}}` is anything else, `{{limit}} <= 0` or `{{window}} <= 0`. |
| `{{remove_rule}}({{ts}}, {{rule_id}}) → bool` | Removes the velocity rule. Returns `false` if there is none. Its id can be added again later. |

**When a rule fires.** When `{{screen}}` screens a transaction at time `{{ts}}` for a card, a rule looks at that card's transactions with a timestamp `t` where `{{ts}} - {{window}} < t <= {{ts}}`, **counting the one being screened**. Every transaction recorded by `{{screen}}` for the card counts, whatever its decision (declined attempts too) and whether or not the rule existed when it was screened. The rule fires if the count (or the sum of amounts) is **more than** `{{limit}}`: exactly `{{limit}}` doesn't fire.

**Decisions now:** `"decline"` if any blocklist matches; otherwise `"review"` if any velocity rule fires; otherwise `"approve"`.

### Example

```
{{add_velocity_rule}}(1, "v-count", "count", 2, 60)          → true
{{add_velocity_rule}}(2, "v-amount", "amount", 50000, 3600)  → true
{{screen}}(10, "t1", "4111", "m-shoes", 1000, "GB")          → "approve"
{{screen}}(30, "t2", "4111", "m-shoes", 1000, "GB")          → "approve"
{{screen}}(69, "t3", "4111", "m-shoes", 1000, "GB")          → "review"    (3 in the last 60s)
{{screen}}(90, "t4", "4111", "m-shoes", 1000, "GB")          → "approve"   (t2 at 30 is outside 30 < t <= 90)
{{screen}}(100, "t5", "5500", "m-tv", 60000, "GB")           → "review"    (60000 > 50000)
```
