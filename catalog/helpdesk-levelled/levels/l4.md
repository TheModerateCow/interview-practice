## Level 4: shift changes and ticket history

Agents go off shift and their work has to be handed over, and team leads want to see everything that happened to a ticket. Every agent starts on shift. Add:

| Method | Behaviour |
|---|---|
| `{{end_shift}}(ts, agent) → list of strings` | `agent` goes off shift and their unresolved tickets are handed over, one at a time in `{{queue}}` order: each goes to the on-shift agent with the fewest unresolved tickets at that moment (counting the tickets already handed over), ties by name. Returns the hand-overs in that order as `"ticket_id:agent"`. Returns `[]`, changing nothing, if the agent doesn't exist, is already off shift, or no other agent is on shift. |
| `{{start_shift}}(ts, agent) → bool` | `agent` is back on shift (they don't get their old tickets back). Returns `false` if the agent doesn't exist or is already on shift. |
| `{{history}}(ts, ticket_id) → list of strings` | Every change to the ticket, oldest first: `"ts:opened"` when it was opened, `"ts:assigned:agent"` each time it got an agent (by `{{assign}}`, `{{auto_assign}}` or `{{end_shift}}`), and `"ts:status"` for each status change. Calls that return `false` or `""` record nothing. `[]` if the ticket doesn't exist. |

**Off shift.** `{{assign}}` to an off-shift agent returns `false`, and `{{auto_assign}}` and `{{end_shift}}` only pick on-shift agents (`{{auto_assign}}` returns `""` when nobody is on shift). A handed-over ticket keeps its status and due time. An off-shift agent still exists: `{{add_agent}}` with their name returns `false`.

### Example

```
{{add_agent}}(0, "maya"); {{add_agent}}(0, "leo"); {{add_agent}}(0, "zoe")
{{open_ticket}}(1, "acme", "low")        → "t1"
{{open_ticket}}(2, "globex", "high")     → "t2"
{{open_ticket}}(3, "initech", "normal")  → "t3"
{{assign}}(4, "t1", "maya"); {{assign}}(4, "t2", "maya"); {{assign}}(4, "t3", "maya")
{{set_status}}(4, "t2", "in_progress")
{{open_ticket}}(5, "umbrella", "low")    → "t4"
{{assign}}(5, "t4", "leo")
{{end_shift}}(6, "maya")                 → ["t2:zoe", "t3:leo", "t1:zoe"]
{{assign}}(7, "t4", "maya")              → false   (maya is off shift)
{{history}}(8, "t2")                     → ["2:opened", "4:assigned:maya", "4:in_progress", "6:assigned:zoe"]
```
