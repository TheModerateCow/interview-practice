## Level 2: scans

Operators want to see a whole record, and to find records by naming convention. Add:

| Method | Behaviour |
|---|---|
| `Scan(ts int, key string) []string` | Every field of `key` as `"field=value"`, sorted by field name ascending. An empty list if the record doesn't exist. |
| `ScanPrefix(ts int, key, prefix string) []string` | The same, but only fields whose name **starts with** `prefix`. An empty prefix matches every field. |
| `ListKeys(ts int, prefix string) []string` | Keys of every record that starts with `prefix` and has at least one field, ascending. |

Sorting is plain Go string order (byte by byte), so `"env"` comes before `"env.HOST"`. Return an empty, non-nil slice when nothing matches.

### Example

```
Set(1, "svc-api", "image", "v1"); Set(2, "svc-api", "env.PORT", "8080"); Set(3, "svc-api", "env.HOST", "0.0.0.0")
Set(4, "svc-web", "image", "w1"); Set(5, "db-main", "size", "large")
Scan(6, "svc-api")                -> ["env.HOST=0.0.0.0", "env.PORT=8080", "image=v1"]
ScanPrefix(7, "svc-api", "env.")  -> ["env.HOST=0.0.0.0", "env.PORT=8080"]
ListKeys(8, "svc-")               -> ["svc-api", "svc-web"]
```
