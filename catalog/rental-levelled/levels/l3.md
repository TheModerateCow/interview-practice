## Level 3: one-way rentals

Customers can now drop a car at a different branch, and each branch wants to see what it has on the lot. Add:

| Method | Behaviour |
|---|---|
| `{{drop_off}}({{ts}}, {{car_id}}, {{branch}})` | The car comes back at `{{branch}}` and is parked there from now on. It is charged like any return, plus a **drop fee of 5000** cents if `{{branch}}` isn't the branch it was rented from. Returns `false`, changing nothing, if the car doesn't exist, isn't rented, or `{{branch}}` is unknown. |
| `{{available}}({{ts}}, {{branch}})` | The cars parked at `{{branch}}`, counted per class, as `"class(count)"`, sorted by class name. Classes with no parked car are left out; an empty list for an unknown branch or an empty lot. |

**Known branches.** A branch is known once a car has been added there with `{{add_car}}`, even if that car has since left.

`{{return_car}}` is a drop-off at the branch the car was rented from: no drop fee. A car that was dropped at a new branch belongs there: `{{rent}}` and `{{return_car}}` treat it as that branch's car.

### Example

```
{{add_car}}(1, "c1", "economy", "downtown"); {{add_car}}(1, "c2", "suv", "downtown"); {{add_car}}(1, "c3", "economy", "airport")
{{available}}(2, "downtown")                   -> ["economy(1)", "suv(1)"]
{{rent}}(3, "maya", "downtown", "economy", 1)  -> "c1"
{{available}}(4, "downtown")                   -> ["suv(1)"]
{{drop_off}}(20, "c1", "airport")              -> true
{{charges}}(21, "maya")                        -> 8000   (1 day at 3000, drop fee 5000)
{{available}}(22, "airport")                   -> ["economy(2)"]
{{status}}(23, "c1")                           -> "available:airport"
```
