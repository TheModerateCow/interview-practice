## Level 3: promo codes and abandoned carts

Marketing runs time-limited promo codes, and carts nobody touches are abandoned. Add to `{{Shop}}`:

| Method | Behaviour |
|---|---|
| `{{add_promo}}({{ts}}, {{code}}, {{percent_off}}, {{min_total_cents}}, {{ttl}}) → bool` | Creates a promo code worth `{{percent_off}}` percent off a cart, valid from `{{ts}}` until `{{ts}} + {{ttl}}`. Returns `false`, changing nothing, if `{{code}}` already exists (even expired), `{{percent_off}}` is outside 1–100, `{{min_total_cents}} < 0` or `{{ttl}} <= 0`. |
| `{{apply_promo}}({{ts}}, {{cart_id}}, {{code}}) → bool` | Attaches `{{code}}` to the cart, replacing any code already attached. Returns `false`, changing nothing, if the cart doesn't exist or is empty, or the code doesn't exist or has expired. |
| `{{active_carts}}({{ts}}) → int` | How many carts exist right now and hold at least one item. |

**Discounts.** `{{cart_total}}` and `{{checkout}}` use the discounted total: when the cart's attached code hasn't expired and the subtotal (price × quantity, summed) is at least the code's `{{min_total_cents}}`, the total is `subtotal - subtotal * {{percent_off}} / 100`, with the discount rounded **down** to whole cents. Otherwise the total is the subtotal. The code stays attached either way, so it starts or stops counting as the cart changes. A code created at `t` with `{{ttl}}` expires at `t + ttl`: from that timestamp on it gives no discount and can't be applied.

**Abandoned carts.** A successful `{{add_to_cart}}`, `{{remove_from_cart}}` or `{{apply_promo}}` touches the cart. A cart last touched at `t` is abandoned at `t + 60`: from that timestamp on it's as if it never existed (`{{items}}` is empty, `{{cart_total}}` is 0, `{{checkout}}` returns -1, `{{add_to_cart}}` starts a new empty cart). Reading a cart (`{{items}}`, `{{cart_total}}`) doesn't touch it.

### Example

```
{{add_product}}(1, "tee", 999, 10)
{{add_promo}}(2, "SAVE15", 15, 0, 100)
{{add_to_cart}}(3, "c1", "tee", 1)
{{apply_promo}}(4, "c1", "SAVE15") → true
{{cart_total}}(5, "c1")            → 850    (999 - 149)
{{active_carts}}(6)                → 1
{{cart_total}}(63, "c1")           → 850
{{cart_total}}(64, "c1")           → 0      (last touched at 4, abandoned at 64)
{{active_carts}}(65)               → 0
```
