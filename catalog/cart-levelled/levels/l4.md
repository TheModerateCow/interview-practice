## Level 4: logging in, order history and cancellations

A guest who logs in brings their cart along, and support needs past orders and a way to cancel them. A cart id is the shopper's id, so a shopper's orders are the checkouts made from their cart id. Add to `{{Shop}}`:

| Method | Behaviour |
|---|---|
| `{{merge}}({{ts}}, {{guest_id}}, {{user_id}}) → bool` | The guest logged in as `{{user_id}}`: the guest cart's lines are added to the user's cart (created if the user has none), the guest cart is removed, and the guest's order history moves to the user. Returns `false`, changing nothing, if `{{guest_id}}` equals `{{user_id}}` or the guest cart doesn't exist or is empty. |
| `{{order_history}}({{ts}}, {{cart_id}}) → list of strings` | Every successful checkout made from `{{cart_id}}` (including those moved in by `{{merge}}`), oldest first, as `"orderTs:total"` where `{{order_ts}}` is the checkout's timestamp and `total` what it charged; a cancelled order shows as `"orderTs:cancelled"`. An empty list if there are none. |
| `{{cancel_order}}({{ts}}, {{cart_id}}, {{order_ts}}) → bool` | Cancels the order placed from `{{cart_id}}` at `{{order_ts}}`: its units go back into stock and no longer count in `{{top_sellers}}`. Returns `false` if `{{cart_id}}` has no such order or it's already cancelled. |

**Merging lines.** For each guest line, the user's quantity becomes the sum of both, capped at the product's current stock, but a user's line never ends up smaller than it was before the merge. **Promo codes.** The user cart keeps its own code if it has one that hasn't expired; otherwise it takes the guest cart's code (if any). The merge touches the user cart. Each shopper's history stays ordered by checkout time after a merge.

### Example

```
{{add_product}}(1, "lamp", 4500, 3); {{add_product}}(2, "bulb", 300, 10)
{{add_to_cart}}(3, "ana", "lamp", 1); {{checkout}}(4, "ana")    → 4500
{{add_to_cart}}(5, "guest", "bulb", 2); {{checkout}}(6, "guest") → 600
{{add_to_cart}}(7, "guest", "lamp", 2); {{add_to_cart}}(8, "ana", "lamp", 1)
{{merge}}(9, "guest", "ana")      → true
{{items}}(10, "ana")              → ["lamp:2"]       (1 + 2, capped at the 2 in stock)
{{order_history}}(11, "ana")       → ["4:4500", "6:600"]
{{cancel_order}}(12, "ana", 4)     → true
{{stock_of}}(13, "lamp")           → 3
{{order_history}}(14, "ana")       → ["4:cancelled", "6:600"]
```
