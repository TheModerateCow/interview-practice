## Level 3: fastest routes

Drivers want the quickest way to a customer, and traffic changes how long roads take. Add:

| Method | Behaviour |
|---|---|
| `{{set_minutes}}(ts, road, minutes) → bool` | The road now takes `minutes` (both ways). Returns `false` if the road doesn't exist. A closed road can be changed too: it stays closed and takes the new time once it reopens. |
| `{{fastest_route}}({{ts}}, {{origin}}, {{dest}}) → int` | The fewest minutes to drive from `{{origin}}` to `{{dest}}` along open roads. `0` if they're the same junction. `-1` if either junction doesn't exist or `{{dest}}` can't be reached. |

The route with the fewest roads isn't always the fastest. A city network has thousands of junctions and roads, and dispatch asks for routes all day, so `{{fastest_route}}` has to stay fast.

### Example

```
(junctions depot, a, b, cust, far; roads r1 depot-cust 30 min, r2 depot-a 8, r3 a-b 7, r4 b-cust 9)
{{fastest_route}}(10, "depot", "cust")        → 24      (depot-a-b-cust)
{{set_minutes}}(11, "r3", 20)                 → true
{{fastest_route}}(12, "depot", "cust")        → 30      (r1 is quicker now)
{{close_road}}(13, "r1")                      → true
{{fastest_route}}(14, "cust", "depot")        → 37
{{fastest_route}}(15, "depot", "far")         → -1
{{fastest_route}}(16, "a", "a")               → 0
```
