## Level 2: closures

Roadworks and accidents close roads for a while, and dispatch wants to see which part of the city a van can still get to. Add:

| Method | Behaviour |
|---|---|
| `{{close_road}}(ts, road) → bool` | Closes the road. Returns `false` if the road doesn't exist or is already closed. |
| `{{reopen_road}}(ts, road) → bool` | Opens a closed road again. Returns `false` if the road doesn't exist or is open. |
| `{{reachable_from}}(ts, junction) → list of string` | Every junction a van can drive to from `junction`, the junction itself included, sorted by id in plain string order. An empty list if the junction doesn't exist. |

**A closed road** can't be driven: `{{reachable}}` and `{{reachable_from}}` ignore it, and `{{roads_at}}` leaves it out. It still exists, so `{{add_road}}` with its id returns `false`, and it keeps its minutes for when it reopens.

### Example

```
(junctions depot, a, b, c; roads r1 depot-a 10 min, r2 a-b 5, r3 b-c 3)
{{close_road}}(8, "r2")                       → true
{{close_road}}(9, "r2")                       → false
{{reachable}}(10, "depot", "b")               → false
{{roads_at}}(11, "a")                         → ["r1:depot:10"]
{{reachable_from}}(12, "depot")               → ["a", "depot"]
{{reachable_from}}(13, "c")                   → ["b", "c"]
{{reopen_road}}(14, "r2")                     → true
{{reopen_road}}(15, "r2")                     → false
{{reachable_from}}(16, "a")                   → ["a", "b", "c", "depot"]
```
