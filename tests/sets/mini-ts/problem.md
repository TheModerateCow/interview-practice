# Top K words

In `topk.ts`, implement `topK(words, k)`: the `k` most frequent words, most frequent first. Ties are broken
alphabetically (plain `<` string comparison). If there are fewer than `k` distinct words return them all; `k <= 0` gives `[]`.

`main.ts` reads `k` on the first stdin line, then words, and prints the result space-separated.
