## Level 3: due dates, renewals and fines

Loans now run for a fixed period, and late returns cost money. Add:

| Method | Behaviour |
|---|---|
| `DueDate(ts int, copyID string) int` | The day the copy's current loan is due, or `-1` if the copy isn't on loan. |
| `Renew(ts int, copyID string) int` | Pushes the current loan's due date back by 14 days (from the **due date**, not from today) and returns the new due date. Returns `-1`, changing nothing, if the copy isn't on loan, the loan is overdue (`ts` is after the due date), or this loan has already been renewed twice. |
| `Fines(ts int, memberID string) int` | What the member owes in cents for late returns. `0` for an unknown member. |

A checkout on day `t` is due on day `t + 14`. Returning on the due date is on time. A copy returned after its due date costs **25 cents per day late**, at most **1000 cents per loan**. The fine is set when the copy comes back: a copy still out adds nothing yet, however overdue. Each new loan starts with no renewals.

### Example

```
AddMember(1, "ana"); AddCopy(2, "D-1", "Dune"); AddCopy(3, "E-1", "Emma")
Checkout(10, "ana", "Dune") -> "D-1"
DueDate(11, "D-1")          -> 24
Renew(20, "D-1")            -> 38
Renew(38, "D-1")            -> 52    (on the due date is fine)
Renew(39, "D-1")            -> -1    (already renewed twice)
Checkout(40, "ana", "Emma")
Return(60, "D-1")           -> true
Fines(61, "ana")            -> 200   (8 days late)
Renew(70, "E-1")            -> -1    (overdue: it was due on 54)
Return(140, "E-1")          -> true
Fines(141, "ana")           -> 1200  (86 days late, capped at 1000)
```
