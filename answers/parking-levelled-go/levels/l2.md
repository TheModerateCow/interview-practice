## Level 2: occupancy and regulars

The operators want to see how full each size is and who parks most often. Add:

| Method | Behaviour |
|---|---|
| `FreeSpots(ts int, size string) int` | How many spots of exactly `size` are free. `-1` if `size` is invalid. |
| `TopVisitors(ts int, n int) []string` | Up to `n` plates as `"plate(visits)"`, where `visits` is the number of successful `Park` calls for that plate so far: most visits first, ties by plate ascending. An empty list if nobody has parked yet. |

A failed `Park` is not a visit. Visits stay counted after the vehicle leaves.

### Example

```
AddSpot(1, "A1", "small"); AddSpot(2, "B1", "medium"); AddSpot(3, "C1", "large")
Park(4, "KX-101", "small"); Park(5, "VN-220", "small")
FreeSpots(6, "small")  -> 0
FreeSpots(7, "medium") -> 0
FreeSpots(8, "large")  -> 1
Leave(9, "KX-101"); Park(10, "KX-101", "small")
TopVisitors(11, 5)     -> ["KX-101(2)", "VN-220(1)"]
```
