## Level 3: reservations

Drivers can book a spot shortly before they arrive. Add:

| Method | Behaviour |
|---|---|
| `Reserve(ts int, plate, size string, ttl int) string` | Reserves for `plate` the spot `Park` would pick right now for a vehicle of `size`, and returns its id. Returns `""`, changing nothing, if `size` is invalid, `ttl <= 0`, `plate` is parked, `plate` already has a live reservation, or no free spot fits. |
| `Cancel(ts int, plate string) bool` | Drops `plate`'s live reservation. Returns `false` if it has none. |

A reservation made at time `t` with `ttl` expires at `t + ttl`: from that timestamp on it holds nothing and can't be cancelled.

While a reservation is live, its spot is **not free**: `FreeSpots` doesn't count it, and other vehicles' `Park` and `Reserve` skip it. When the plate itself calls `Park` while its reservation is live, it goes into its reserved spot (even if a better spot has opened up since) and the reservation is used up. A plate whose reservation expired parks like anyone else. A reservation is not a visit; the park is.

### Example

```
AddSpot(1, "A1", "small"); AddSpot(2, "A2", "small")
Reserve(10, "KX-101", "small", 30) -> "A1"
Park(12, "VN-220", "small")        -> "A2"   (A1 is reserved)
FreeSpots(13, "small")             -> 0
Park(14, "TR-900", "small")        -> ""
Park(20, "KX-101", "small")        -> "A1"   (its reserved spot)
Leave(22, "VN-220")                -> true
Reserve(23, "TR-900", "small", 5)  -> "A2"
FreeSpots(27, "small")             -> 0
FreeSpots(28, "small")             -> 1      (expired at 28)
```
