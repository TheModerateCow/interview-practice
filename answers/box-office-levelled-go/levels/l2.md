## Level 2: rankings

The promoter wants to see who is buying and what is selling. Add:

| Method | Behaviour |
|---|---|
| `TopBuyers(ts int, eventID string, n int) []string` | Up to `n` buyers of `eventID` as `"buyer(qty)"`: most tickets first, ties by buyer name ascending. Only buyers who currently own at least one ticket. An empty list if the event doesn't exist or nobody owns a ticket. |
| `BusiestEvents(ts int, n int) []string` | Up to `n` events as `"eventID(sold)"`, where `sold` is the number of tickets currently owned for it: most sold first, ties by event id ascending. Events with nothing sold are included. |

Refunds count: a refunded ticket is no longer owned or sold.

### Example

```
CreateEvent(1, "jazz-night", 10); CreateEvent(2, "folk-fest", 10)
Buy(3, "jazz-night", "maya", 2); Buy(4, "jazz-night", "leo", 2); Buy(5, "folk-fest", "sam", 5)
TopBuyers(6, "jazz-night", 5) -> ["leo(2)", "maya(2)"]
BusiestEvents(7, 5)           -> ["folk-fest(5)", "jazz-night(4)"]
```
