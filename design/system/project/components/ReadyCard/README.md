# ReadyCard

The screen before the clock starts: who, what, how long and the rules. Never the problem.

- Provide: `.ready-card` with an `eyebrow` (company · role · round type), the set title in `h1` at `display` size, pills (language, difficulty, minutes), the rules as markdown under a "Before you start" `label`, and **Start interview** (`btn-solid btn-lg`) with the note "The clock starts when you press Start."
- Don't show the problem, part names, tags, file names or how many parts exist; the API doesn't return them before Start either.
