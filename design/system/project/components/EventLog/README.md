# EventLog

Where the time went: every start, run, submit, reveal and end, with the minute it happened, shown on the end card and used in the debrief.

- Provide: `.events` with one row per `[minute, text]` from session.json; minutes right-aligned in mono.
- Mark anything after the time limit with `<em>(after time)</em>` (warn). Never edit or hide events.
